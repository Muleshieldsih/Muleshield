What the three models optimise
1  Mule detection
GRAPHSAGE · 2 LAYERS · 64-DIM
hv(k) = ReLU( W(k) · [ hv(k−1) ‖ meanu∈N(v) hu(k−1) ] )
p(mule) = σ( w · hv(2) + b )
Class-weighted cross-entropy, then isotonic calibration so the probability means what it says.
2  Cash-out location
CONDITIONAL LOGIT · 25 CANDIDATES
P(atmi | C) = e w·log xi ⁄ Σj∈C e w·log xj
maxw  Σgroups log P( chosen | C )
Choice is multiplicative (proximity × risk × affinity × habit), so logs make it linear.
3  Time to cash-out
GRADIENT BOOSTING · XGBOOST
ŷ = Σm=1M fm(x),  fm ∈ F
min  Σ ( y − ŷ )2 + Σm Ω( fm )
Predicts minutes to withdrawal; q05 / q95 models add a band, not a false point estimate.
